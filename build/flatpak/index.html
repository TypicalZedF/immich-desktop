Immich Desktop for Linux

An unofficial desktop companion for a self-hosted Immich server, as a Flatpak. Installing it this way means updates arrive through Flatpak (Discover, GNOME Software or flatpak update).

Install

Open io.github.TypicalZedF.ImmichDesktop.flatpakref with your software center, or run:

flatpak install --user https://typicalzedf.github.io/immich-desktop/io.github.TypicalZedF.ImmichDesktop.flatpakref

It needs the GNOME runtime from Flathub, which is added automatically.

Source code, Windows downloads and release notes: github.com/TypicalZedF/immich-desktop. Immich Desktop is not affiliated with or endorsed by the Immich project.
